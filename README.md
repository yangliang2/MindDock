# MindDock

> **An open-source, zero-inbox attention dock that lives on your desktop edge and phone lock screen — bridging the gap between work and life without opening an app.**

**MindDock** 是为“事情太多、频繁被打断、不写传统笔记也不排日程表”的人设计的开源跨场景注意力停靠坞：

- **0 步闪投（Drop）**：不打开复杂软件、不选文件夹、不填日期——在电脑前动嘴/按住热键随口一丢，在外面按锁屏或随身键说半句，1 秒清空大脑内存。
- **跨场景无缝接力（Shift）**：
  - 上班在电脑前顺口丢的**生活琐事**，白天隐身不打扰工作；离开工位后自动浮现在**手机锁屏卡片**上接住你。
  - 下班在路上/睡前冒出的**工作灵感**，晚上隐身不打扰休息；后台 Agent 连夜替你探路备料（**Prep**），第二天电脑一亮屏，带着半成品结论稳稳停在**电脑边角**等你。
- **有限台面 + 印象打捞（Dock & Recall）**：眼前的停靠台永远只保留当下活着的寥寥几件事，干完即消；其余全部沉入水下（**Deep**），日后凭一句模糊印象随时捞回。
