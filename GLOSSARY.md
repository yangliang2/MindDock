# MindDock

MindDock manages a person's active working memory across work and life transitions, capturing raw thoughts without friction, preparing them in the background, and surfacing only what belongs to the user's current context while keeping everything else retrievable by vague impression.

## Language

**Drop（闪投）**:
An unstructured, raw thought, obligation, or fragment captured on the fly without leaving the user's current activity or choosing any category.
_Avoid_: Note, document, entry, post

**Dock（停靠台）**:
A bounded, ambient surface visible at a glance (at the work desk or on the phone lock screen) that holds only the few active items relevant to the user's current context.
_Avoid_: Dashboard, inbox, todo list, folder

**Berth（泊位）**:
A single slot on the Dock holding one active thread or actionable item along with its prepared context; once resolved or dismissed, the berth is freed.
_Avoid_: Card, ticket, row, task

**Shift（换场）**:
The automatic transition between the user's Work context and Life context, which determines which items surface onto the active Dock and which step back out of sight.
_Avoid_: Mode toggle, profile switch

**Prep（备料）**:
Background enrichment performed while an item waits off-stage—gathering context, researching feasibility, or preparing next steps—so the item arrives on the Dock ready for a quick decision rather than starting from scratch.
_Avoid_: Auto-summary, AI rewrite

**Deep（深海）**:
The invisible long-term memory layer where completed items and non-actionable thoughts sink out of sight, eliminating visual clutter.
_Avoid_: Archive folder, trash, backlog

**Recall（打捞）**:
Retrieving past items from the Deep using a natural-language vague impression rather than exact keywords or folder navigation.
_Avoid_: Keyword search, filter query
