# Cloud-Reachable Hub with Native macOS Edge Client and Zero-Install Mobile Surface

MindDock bridges two physical contexts—working at a Mac desk and being away on an Android phone—so state cannot live solely inside a local desktop process that goes offline the moment the laptop lid closes. At the same time, domestic Android ROMs (ColorOS, HyperOS, OriginOS) block third-party `VoiceInteractionService` bindings and aggressively kill non-whitelisted background socket processes, while macOS penalizes always-on microphone or `CGEvent` key-tap listeners with battery drain and intrusive privacy prompts.

We therefore split V0.1 into an always-reachable lightweight **MindDock Hub** (deployable to serverless/cloud or run locally with one command) paired with a single-bundle native Swift **MindDock macOS** menu-bar/edge client (`Carbon RegisterEventHotKey` + sleep/lock notifications + lightweight heartbeat timeout fallback, requiring zero Accessibility permissions and zero sleep wake-locks) and a **zero-install mobile surface** (HTTPS mobile web quick-Drop PWA paired via QR code + webhook push adapters such as ServerChan/PushPlus/Feishu that ride whitelisted system channels straight onto the Android lock screen without sideloading an APK).
